# 追加材料 7区分の接続表

作成：2026年10月20日（JST）／ 実装担当
対象：10月20日 004 のご判断2（オッズ以外の材料をいつ載せるか）

いま `source_registry` に載せているのは、6時点（21・18・15・12・9・6分前）の
`win_odds`・`place_min`・`place_max` だけです。
7区分それぞれについて、**実際にDBに何があるか**を調べました。
「無いから UNAVAILABLE」ではなく、「有るのに繋いでいない」ものを分けて書きます。

区分の状態は3つです。
**接続済み**／**未接続（実データあり）**／**真の欠損（実データなし）**

　`source_kind` と `formula_id` に「日付精度」と明記します。

　追加0日。いまのままです。
