## 1. `app/Http/Controllers/Api/AiController.php`

### r12.2 の判定（`R122-MODE`）

| 内容 |
| --- |
| 旧「不明が3信号以上なら UNKNOWN」を**使わない**ようにした（r12.2 にこの条件はありません） |
| 旧「UNKNOWN なら配分は MIXED を流用（MIXED_PROVISIONAL）」を**廃止** |
| `mode_status` / `allocation_mode` / `mode_policy_id` / `selection_enabled` / `display_rating` / `S0` を返すようにした |
| 可能な mode が1つなら CONFIRMED（他に不明があっても選出可） |
| 不明が X6 だけで S0=1 なら MIXED、S0=3 なら VOLATILE、`mode` は UNKNOWN のまま |
| それ以外の複数 mode は UNRESOLVED（`allocation_mode=null`・選出しない） |
| 星は CONFIRMED で、取り得る S が全部同じ星のときだけ |

### 配分（`R122-QUOTA` / `R122-ALLOC`）

| 内容 |
| --- |
| C7 混戦を **4/2/1 → 3/3/1** に修正（変更計画書3章・詳細設計書6章・`r122_contract.json` と一致） |
| `allocation_mode=null` では配分を作らない |
| 構造調整（実在しない帯の枠を D→B→A で移す。`reason=BAND_CAPACITY` を省略しない） |
| 2nd の配分（C≦5 は同じ。C>5 は B・D を保って A=5−B−D、cap=5） |
| N≦3 は C/0/0 |

### 正確な数値（`R122-EXACT` / `R122-EXACT2`）

| 内容 |
| --- |
| 任意精度の十進数比較を追加（`decNorm` / `bigMul` / `bigCmp` / `cmpProd` / `cmpRatio`） |
| `v04Pairs` が元値（十進数の文字列）を保持し、判定を元値のたすき掛けで行う |
| `v04DeriveFlags` の X1〜X5 を元値の判定に置き換え |
| 複勝の短縮率も割り算せずに比較（19×前≧20×後／97×前≧100×後） |
| 順位点を分数（分子・分母）のまま持ち、比較と `+5` を整数で行う |
| 閾値の直前・ちょうど・直後、128桁、指数表記、手組み経路の検算を追加 |

### r12.2 の実装一式（ファイル下部のクラス）

| クラス | 役割 |
| --- | --- |
| `BaganrikiSignals` | 三値論理、ペアの W/P、X1〜X6・Z、S、mode 一式 |
| `BaganrikiAllocation` | 目標頭数 C、3帯 quota、構造調整、2nd 配分、帯判定 |
| `BaganrikiTime` | スロット予定と期限、cutoff、input_freeze、公開・応答期限、RFC3339 の厳密読込 |
| `BaganrikiAcquisition` | 採用バッチの選定、6分前の全頭同一バッチ条件、`collection_audit` |
| `BaganrikiSnapshot` | 4つの頭数、出馬表必須、凍結順位の非減少、共通JSONとSHA-256 |
| `BaganrikiRanking` | SCORE/EVIDENCE、順位点、統合と+5、評価後不足、取消後の配分 |
| `BaganrikiResponse` | BEGIN/END 抽出、応答全体の照合、馬ごとの隔離、訂正の採否 |
| `BaganrikiPublicView` | 表示状態、暫定の文言、読取DTO、理由コード |
| `BaganrikiMl` | 機械学習（断層学習）。r12.2 とは別系統。整理のため切り出したもの |

### 読取API（`R122-API`）

`GET /api/baganriki/r12-2/races/{race_id}`
正式公開とライブ状態を分けて返します。原AI応答・予約token・内部認証情報は返しません。
