# ③ 既存データが変わっていないこと ─ 方法と結果

作成：2026年10月20日（JST）

---

## 1. ご指摘のとおりです

前回の報告で出した「既存テーブルの件数が変わっていない」は、
**行数が同じであることの証拠にすぎません**。
元値が1つも変わっていないことの証明にはなりません。訂正します。

---

## 2. 対象の列と並び順

元値の列だけを `id` の昇順で連結し、その md5 を取ります。
自動採番の `id` は連結の中身には入れず、並び順にだけ使います。

| テーブル | 連結する列（この順） |
| --- | --- |
| `t_horse_odds_finder_odds` | date, kaisuu, basho, day, race, num, minutes_before_start, odds, fuku_min, fuku_max |
| `t_horse_odds_finder_horses` | date, kaisuu, basho, day, race, waku, num, name |
| `t_horse_odds_finder_races` | date, kaisuu, basho, day, race, start_time, num_horses |
| `t_horse_odds_finder_race_results` | date, kaisuu, basho, day, race, num, result |

区切りは列間が `|`、行間が `;` です。
数値へ変換せず、**DBに入っている文字列のまま**連結します。

---

## 3. 比較方法（そのまま再実行できます）

`07_元値の指紋.sql` を同梱しています。

```sql
SELECT 'odds' t, COUNT(*) rows_n,
 MD5(GROUP_CONCAT(CONCAT_WS('|',date,kaisuu,basho,day,race,num,
   minutes_before_start,odds,fuku_min,fuku_max) ORDER BY id SEPARATOR ';')) fp
 FROM t_horse_odds_finder_odds
UNION ALL SELECT 'horses', COUNT(*),
 MD5(GROUP_CONCAT(CONCAT_WS('|',date,kaisuu,basho,day,race,waku,num,name)
   ORDER BY id SEPARATOR ';')) FROM t_horse_odds_finder_horses
UNION ALL SELECT 'races', COUNT(*),
 MD5(GROUP_CONCAT(CONCAT_WS('|',date,kaisuu,basho,day,race,start_time,num_horses)
   ORDER BY id SEPARATOR ';')) FROM t_horse_odds_finder_races
UNION ALL SELECT 'race_results', COUNT(*),
 MD5(GROUP_CONCAT(CONCAT_WS('|',date,kaisuu,basho,day,race,num,result)
   ORDER BY id SEPARATOR ';')) FROM t_horse_odds_finder_race_results;
```

**r12.2 の作業を始める前に、この指紋を取っていませんでした。**
したがって「作業前後で同じ」という形では示せません。

## 6. 補強できる材料

### 6-1. 新しいコードから既存テーブルへの書き込みが無いこと

r12.2 で足したコード（`@ANCHOR-20261020-R122*` の範囲）に、
`t_horse_odds_finder_*` への INSERT / UPDATE / DELETE / TRUNCATE が
**1か所もない**ことを機械的に確認しました。

書き込み先は、新しく作った `baganriki_*` の9テーブルだけです。

### 6-2. 各馬CSVが1バイトも変わっていないこと

各馬CSV（922行＋見出し）は、DBの元値をそのまま書き出したものです。
このファイルの md5 は

```
909c416342f4a91489d326d647103799
```

で、10月19日の v6 から今日の版まで**1バイトも変わっていません**。
コードは何度も入れ替えていますが、元値は動いていない、という傍証になります。

ただしこれは 2026-10-17・18 の範囲だけの話です。
テーブル全体については第4項の指紋が基準になります。
