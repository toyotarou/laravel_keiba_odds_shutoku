# 最重要：断層構造と3人気帯配分 v0.3（ルール仕様・研究初期値）
**本ファイルの数値閾値・配分は未検証の初期提案**。後付け最適化済みの成績ではない。`config_version=v03-20261012-proposal` として保存し、既知レースの結果から閾値をその場で変えない。実装はまずSHADOWのみ。

## 1. 固定入力・3帯
- `race_id`、6分前`original_snapshot_hash`、N、`target_count`、同時点の6分前単勝人気を固定。
- A=1〜6人気、B=7〜10人気、D=11人気以下（大穴、Deep）。「C」は目標頭数と混同するため帯IDはA/B/D。
- 21・18・15・12・9・6分前（6時点、5区間）の全馬単複オッズ、馬番が固定した隣接ペアを使う。馬番が変わったらその境界は不明にし、別の馬で比較しない。
- `W(k,t)=下側単勝/上側単勝`、`P(k,t)=下側複勝最小/上側複勝最小`。W>=2.00を単勝壁、P>=1.50を複勝補強とするのは**暫定閾値**。P>=2.00も感度比較。
- `k=1..5`は6人気以内の上位内部断層、`k=6`は人気側/中穴境界、`k=7..10`は中穴領域/中穴〜大穴境界、`k>=11`は大穴内部。

## 2. 候補を選ぶ前の「レース構造判定」
入力の利用可能性は判定と独立に先に評価。下記は各0/1の機械フラグとする。`TRUE/FALSE/UNKNOWN`の3値をログ化し、不明をfalse扱いしない。
**X1 境界弱化（重み2）**：k<=6において、同一馬番ペアで `W(k,21)>=2.00` かつ (`W(k,6)<2.00` **または** `(W(k,21)-W(k,6))/W(k,21)>=0.20`) が1つ以上。消滅と縮小は同じX1として1回だけ数える。
**X2 単複乖離（重み1）**：k<=10に `W(k,6)>=2.00` かつ `P(k,6)<1.50` の断層が1つ以上。P欠損なら不明。乖離は波乱を保証しない。
**X3 中位接近（重み1）**：`k=3,4,5,6` の4境界すべてが有効で `max(W(k,6)) < 1.50`。N<7ならUNKNOWN。3〜7番人気の接近を評価する暫定基準。
**X4 穴側の絶対支持（重み1）**：6分前7番人気以下で、異なる2頭以上に、21→6分の複勝最小短縮5%以上 **または** 9→6分の複勝最小短縮3%以上が成立。対象区間の実際の値で確認し、欠損は不明。相対流入1位だけを短縮に数えない。
**X5 中穴の壁（重み1）**：k=7..10の単勝で `W(k,6)>=2.00` が1つ以上。中穴側が断層の上に集まる構造も観測できるが、X5単独では大波乱扱いしない。
**X6 類似統計（重み1・条件付き）**：発走前に利用可能な同条件の過去類似レースが50レース以上あり、7人気以下の3着内進入率が同条件の比較基準率より**10パーセントポイント以上高い**（どちらの率も母数定義を同一にする）。基準率が取得できなければUNKNOWN。履歴の同じレース/未来データは除外。
**Z 安定上位（-2）**：k=1..5に `W(k,6)>=2.00`、`P(k,6)>=1.50`、`W(k,21)>=2.00` が成立する**異なる2境界以上**。単複一致の上位壁が持続している強い安定候補。ただし上位の結果を保証しない。

判定式：`S = 2*X1 + X2 + X3 + X4 + X5 + X6 - 2*Z`。Sは波乱「確率」ではなく仮説の離散スコア。
未知がX1〜X6/Zのうち **3項目以上** の場合 `mode=UNKNOWN`、ログに範囲（未知を0/1にしたときのS_min/S_max）を記録。UNKNOWNの暫定配分は堅め扱いではなく**中立（MIXED）配分**で、別ラベルのまま保持する。未知2項目以下でも、未知を0/1にした全組合せのモードが変わる場合は `mode=UNKNOWN` とする（結果への先入観で恣意的に判定しない）。
確定したSに対し S<=1 → `FIRM`（堅め）、2<=S<=3 → `MIXED`（混戦）、S>=4 → `VOLATILE`（波乱警戒）。`EXTREME`（大波乱）は**研究用のみ**、独立した追加検証完了までLIVEのmodeに使わない。

## 3. 3帯の基本配分（A=1〜6、B=7〜10、D=11以下）
|目標頭数|堅め FIRM|混戦 MIXED / 判定UNKNOWN|波乱 VOLATILE|大波乱 EXTREME（研究専用）|
|---|---|---|---|---|
|7| **5/2/0** | **4/2/1** | **3/3/1** |2/3/2|
|6|4/2/0|3/2/1|3/2/1|2/3/1|
|5|4/1/0|3/2/0|2/2/1|2/2/1|
|4|3/1/0|2/2/0|2/1/1|2/1/1|
|1〜3|`min(N,C)`、実在帯の中で得点比較|同左|同左|研究のみ|

この表は**目標枠**であり「必ず該当人気帯の馬を選ぶ」という意味ではない。目標頭数を超えない。`N<=10`でD帯が存在しない等、存在不可能な枠は未使用扱いで補充方針へ。研究専用EXTREME配分は本番初期スイッチで無効。前版v0.2の2帯に集約したときの目標数（C7 5+2/4+3/3+4など）は概ね維持するが、新v0.3ではD帯の強制的な選出を禁止し、確かな証拠がないと未充足にする。

## 4. 帯内選出の具体的順序（固定・再現可能）
1. **全馬**に新100点の内訳と根拠、score_statusを作成。公開候補行のみの馬もDB妥当性・点数の正本を検証する。通常の最終選出には有効な公開候補行、または**検証済みの全頭得点からPHPが生成した候補行**を使う。内部JSONが未検証なら推測補完しない。
2. 7人気以下の旧 `F AND(R OR O)` は三値資格として保持し、帯内の**参考根拠**にする。**不成立は候補削除の条件ではない**。
3. 独立根拠：市場流入、能力適性、断層構造＋他根拠、単複乖離、類似統計/OPI。両市場の同じオッズ変化を2つと数えない。Tier A=2種類以上、Tier B=1種類以上で説明可能、Tier C=有効根拠なし。Aを優先比較、Bは次点、Cを枠埋めで強制採用しない。根拠の強さ・妥当性を全頭採点、信頼度小計、同帯順位に反映。
4. 各帯で `score_status=valid` かつTier A/Bの馬を、**統合選出用スコア降順 → 信頼度小計降順 → 6分前複勝支持根拠が妥当ならその順位 → 馬番昇順** で選び、それぞれの目標枠へ。スコアの算定/不明の扱いは旧版の丸め規則と互換を試験する。
5. **帯内不足のとき**：まず同帯で有効な次順位がいないか確かめる。次に、他帯のTier A→Bから統合スコアの高い順に空き枠のみ補う。元の各帯目標/実配分と`CROSS_BAND_FILL`を記録。D帯に根拠がなくA/Bから埋める場合も許すが、堅めのD=0枠へ11人気以下を自動追加しない。
6. 他帯にも根拠がなければ**選出頭数は目標未達**のまま公開し、`PARTIAL_COUNT`を記録。HTTP500は禁止。選出理由は元値・有効全頭採点からのみ定型生成し、購入回避フラグにより候補を除外しない。
7. 同じ馬が重複、存在しない馬番、点数矛盾、取消、入力ハッシュ不一致等は現行2026-10-06版の妥当性規則に従い理由ログを作る。有効AIなしは `UNDETERMINED`。0頭回避例外は現在の正式フローとして**シャドーで再現比較**し、v0.3新方式に無条件移植しない。

## 5. 研究用の大穴特例（初期LIVE禁止）
「堅めなのに非常に強い11番人気以下」が存在する場合、D帯0枠をA/Bから1枠変更した反事実比較 `EXCEPTIONAL_DEEP=shadow_only` を記録する。発動条件はTier A、同条件能力の有効実績、独立の市場/断層根拠、欠損のない得点等を全て満たす研究案。これはv0.3の本番既定配分を**変更しない**。比較で有効性がなければ採用しない。

## 6. テスト用の仮想例（着順・実レースではない）
- N=16、X1=1、X2=1、X3=1、その他X=0、Z=0 → S=4、`VOLATILE`、target=7、quota=3/3/1。
- N=16、X1=0、X2=0、X3=0、X4=0、X5=0、X6=0、Z=1 → S=-2、`FIRM`、quota=5/2/0。
- N=16、S=3、すべて既知 → `MIXED`、quota=4/2/1。
- N=12、`VOLATILE`でも11番人気以下が根拠不足 → target=5でquota 2/2/1だが、D=0実配分になり他帯から補充、または目標未達。後日結果を見てDに追加しない。
- X1の21分前ペアが別馬と入れ替わった場合 → そのペアはUNKNOWN、順位移動は別値に記録。欠損を断層消滅と誤認しない。

## 7. ML連携（別モジュール・段階導入）
最初の3帯配分判定は**MLの予想値に依存しない固定ルール**。1000有効レース到達で機械学習シャドー、後日の未使用200レース＋明示承認後に順位だけ最大±2相当・入替最大1頭を検証、本番反映可。未使用500レース後の別審査で `quota(A,B,D)` の移動を**最大1枠**認める余地を検討し、当該レースのML起因入替合計は最大1頭。モデルのM2/M3はレース単位であり、特定馬の好走確率と混同しない。公開点・DB値を変更しない。
