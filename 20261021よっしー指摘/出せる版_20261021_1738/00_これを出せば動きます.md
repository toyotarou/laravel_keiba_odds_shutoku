## 3. 今回入れた見張り（010の7章⑤）

読取API `GET /api/baganriki/r12-2/races/{race_id}` に
**認証が1つも掛かっていませんでした**（`routes/api.php` 150行目）。
画面（Flutter）にも**誰にでも見える「r12.2」のボタン**が出ています
（`race_content_page.dart` 909行目付近。管理者判定も debug 判定も無し）。

記録が0件のうちは空が返るだけですが、**24日に旗を上げた瞬間、
12レースの予想が一般の利用者に見えます。** race_id は
「日付-回-場-日-R」なので総当たりも簡単です。

**既定で閉じました。**

| `BAGANRIKI_R122_READ` | 動き |
|---|---|
| 未設定・`key` | 鍵が合ったときだけ返す（**既定**） |
| `open` | 誰でも見られる |
| `off` | 誰にも見せない |

鍵は `BAGANRIKI_R122_READ_KEY` に入れ、
`X-R122-Key` ヘッダか `?r122_key=` で渡します。
**鍵が未設定なら、誰も中身を見られません。**
`.env` には何も足していません（足さない状態が「閉じている」です）。

**断るときも HTTP 200 で返します。**
画面の `lib/data/http/client.dart` は 2xx 以外を全部例外にするので、
404 だと画面に `Exception: http 404 [url=https://…]` と生の文字列が
出ます。200 で、いつもの形のまま `state=UNAVAILABLE` と理由を返すので、
画面は「この記録はまだ公開していません」と読める形で出ます。
**Flutter は1行も直していません。**

## 4. 24日に検証する人が中身を見る方法

PWAの画面からは見えません（鍵を渡さないため）。URLを直接開きます。

```
1. サーバの .env に鍵を足す
   BAGANRIKI_R122_READ_KEY=<好きな文字列>
2. php artisan config:clear
3. ブラウザで
   https://baganriki.com/api/baganriki/r12-2/races/20261024-5-05-1-1?r122_key=<鍵>
```

鍵を消せば、また誰も見られなくなります。
