## 6. 踏んだ落とし穴（同じのを踏まないために）

| 何 | どうなるか |
|---|---|
| **macOS の rsync は 2.6.9 で `--chmod` が無い** | `invalid argument` で**転送されないのに先へ進みます**。古いコードで試験が通って紛らわしい結果になります。`--chmod` は使わない |
| **ssh し直すと home に居る** | `cd /var/www/horse_odds_finder` を忘れると `artisan` が見つからず、**何も出ずに終わります** |
| **`php artisan cache:clear` は権限で失敗する** | `storage/framework/cache` が apache 所有。無視してよい。効くのは `config:clear` |
| **`curl http://127.0.0.1/...` は nginx の 404** | Host が無いのでアプリまで届きません。`https://baganriki.com/...` で叩く |
| **`??` は null も「無い」と見なす** | キーの有無は `array_key_exists` で見る |
| **`Http::fake()` は呼ぶたびに積み重なる** | 置き換えではありません。登録は1回だけにして、参照渡しで中身を切り替える |
| **Command は `App\Console\Commands` 名前空間** | `BaganrikiTime::` などは完全修飾が必要。`self::r122RaceId()` も不可 |
| **期限は「日付＋発走時刻」から出す** | 発走時刻だけ動かしても、日付が過去なら期限も過去になります |
