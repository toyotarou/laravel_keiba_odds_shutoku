## 2. 最小で出すなら

**`AiController.php` の1本だけでも動きます。**

Job に触る行は10か所ありますが、すべて

1. `BaganrikiWorker::jobs()`（旗 `BAGANRIKI_R122_JOBS`。既定 `0`）
2. `class_exists(\App\Jobs\...)`
3. `R122Job::ready()`（`jobs` 表の有無）

の順に守られています。旗が `0` なら 1 で止まるので、`app/Jobs` が
無くても、`config/queue.php` に `r122` の節が無くても、
待ち行列の3つの表が無くても落ちません。

## 3. できれば `app/Jobs` も一緒に

`AiController.php` 単体でも壊れませんが、Job の実装が入らないことに
なるので、010の2章への回答が「設計は書いたが現物が無い」に戻ります。
**5本をまるごとコピーするだけ**なので、入れられるなら入れてください。
置くだけでは何も動きません（旗が `0` のため）。

## 4. 動かすための条件（旗を上げるとき）

旗を上げるときだけ、次の3つが要ります。いまは要りません。

1. `config/queue.php` の `connections` に `r122` の1節
   （`driver=database` / `retry_after=300` / `after_commit=true`）
2. 待ち行列の3表（`jobs` / `job_batches` / `failed_jobs`）をDDLで作る
   **`php artisan migrate` は打たないでください。**このプロジェクトには
   baganriki 系の migration が1本も無く、打つと関係のない未適用の
   migration まで走ります。
3. `.env` に `BAGANRIKI_R122_JOBS=1`（`BAGANRIKI_R122_QUEUE` も `1` が要る）

節とDDLの全文は、提出物の `01_版とハッシュ.txt` に載せてあります。
