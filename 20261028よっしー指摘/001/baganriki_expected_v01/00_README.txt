現行の試験を進めたあと、結果と照合するための独立した改善案です。

中心の式
  p0 = (同人気順位の好走回数 + 1) / (基準集団のレース数 + 2)
  p_raw = (類似例の重み付き好走回数 + 20×p0) / (類似例の重み合計 + 20)
  改良期待スコア = 100×校正関数g(p_raw)

「3着以内」と「5着以内」を別々に計算します。
未校正の場合はg(p)=pとして、未校正の試算値と明記します。
類似度・重み・欠損・取消・校正・時刻条件は計算仕様に定義しています。
20等の数値は比較開始用の仮設定であり、最適と実証された値ではありません。
現行の「過去中央値オッズ÷現在オッズ」は別項目として保持します。
